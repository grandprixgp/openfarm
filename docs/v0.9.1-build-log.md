# openfarm v0.9.1 Build Log

Date: 19 Nov 2026

v0.9.1 resolves all findings from the full-codebase Carbon (High) audit of `v0.9.0` (`c989644`) and ships bare `openfarm` Automode TUI + command palette, frontier card-complexity triage (`openfarm triage`), and mixture-of-frontiers review (`openfarm frontier-review`).

## Changes

### Audit Fixes (from Carbon High full-codebase review of `c989644`)
- **Critical runtime & git/land safety (`a02ba04`):**
  - `Git._run` prepends `-c core.hooksPath=/dev/null` so target repo hooks never execute unconfined on the host.
  - Initialized `restatement = None` in `_checker` (fixing `UnboundLocalError` in `checker_mode = "single-pass"` / `--profile lean` when `adjudicate_checker` runs), caught unexpected exceptions cleanly in `CardRun.run`, and guarded `fut.result()` in `SwarmRunner.run`.
  - Hardened `openfarm land`: refuses any card not in `in_review` or without an approved `verdict.json` (`clean` / `minor-fix`), creates trial worktrees under `0700` `ctx.state.worktrees`, runs `_configured_pack` + `prepare_worktree` + `suite_green`, and fails cleanly if `mark_done` refuses.
- **Security & isolation hardening (`4906b61`):**
  - Added `Grep(...)` and `Glob(...)` deny rules in Claude ACP settings; rejected ACP `read-only` directory `search` overlapping `never_touch` / `forbidden_files`.
  - Fixed multi-symlink `confine.scan_masks` deduplication (`(target, rel)` + ancestor cycle check); mounted empty dir in `agy_native_acp.py` when `tool_policy == "none"`.
  - Fixed mid-run OAuth login refresh (`_initial_creds_bytes` + `auth_mode`/`auth_file` guard in `acp.py`), rejected symlinks in `logins.refresh_isolated` and `link_node_modules` (`O_NOFOLLOW`), and fixed inverted `[runner] confine_network` polarity (`"on"` -> `--unshare-net`) while preserving explicit `confine = "bwrap"` across `--profile lean|balanced`.
  - Restricted `openai_compat._within` to `http`/`https` and rejected `%2f`/`%5c` traversal; enforced `_safe_id` in `FileCardSource._path` and skipped symlinks in `_seed_from_base`; added `start_new_session=True` + `os.killpg` on timeout in `DirectRunner.exec`; set `0700` on `StateDir.root` and scoped `bootstrap.py` key-parent `chmod 0700` to home paths.
- **Language packs, polyglot, mutation & banned-patterns (`150cd01`):**
  - Fixed Vitest/Jest `-t` regex (`(?:^|\s)(?:...)$`) to match `describe(...)`-nested `fullName`s, hardened `_extract_json_object` against noisy stdout via `JSONDecoder().raw_decode`, and added `top` scoping.
  - Routed `check_eligibility` through `cfg.language_for_unit(card.unit)` and added `"go.mod"` to `_UNIT_MANIFESTS`.
  - Fixed Go subtest `-run` splitting on `/`, gated `gofmt` on `has_gofmt`, added Go `panic(...)` scaffold validation and `*_test.go` counter-test paths, fixed Go/Rust `/* ... */` block-comment bypasses, and removed copy-pasted JS rules (`\.skip\(`, `\.only\(`, `eslint-disable`, `@ts-ignore`) from `RustPack.BANNED_ANYWHERE`.
  - Fixed `mutation_gate` to fail when `timeout > 0 and judged == 0`, added `"scoped"` to `mutate.read_outcomes`, and skipped files with empty changed line sets on delete-only diffs.
- **Token accounting, concurrency & multi-wave scaling (`49117b7`):**
  - Replaced `fsource.prepare()` in `tui.py` `_read_cards_readonly` with read-only `git ls-tree` + `git show` (eliminating cross-process `git reset --hard` races).
  - Synced Wave 2+ cards added on `base_branch` on every `FileCardSource.prepare()`.
  - Propagated `tokens_in_fresh`/`tokens_in_cached` in `_card_mm_usage()`, fixed 2x token double-counting in `tui.py`, passed `first_attempt=1` in single-pass checker, checked `card.deps` in `CoordinatorRuntime.can_launch` and full `effort_ladder` in `retry_covers`, expanded `harness_scope.py` to `.ts`/`.tsx`/`.js`/`.jsx`/`.go`, and bumped `globs_overlap` cache to `16384`.
- **Review UX, dedup & stale docs (`bef8d93`):**
  - `openfarm review` now displays gate pass/fail counts and findings from `gates/` + `card-record.json` and guards against interactive `input()` inside TUI background capture (`OPENFARM_TUI_CAPTURE=1`).

### New Features in v0.9.1
- **Frontier card-complexity triage & mixture-of-frontiers review (`84c83c0`):**
  - `openfarm_core/triage.py` + `openfarm triage [CARD...] [--apply] [--heuristic] [--script FILE] [--json]`: scores cards (`low | medium | high | split`) in one batched frontier call (or deterministic heuristic), recommending supervision profile, starting effort, and split flags; tightened `pre_review_when = "on-flag"` to trigger on `flagged_patterns` and `checker_pass2.verdict == "changes-requested"`.
  - `openfarm_core/frontier_review.py` + `openfarm frontier-review --scope card|diff|repo [TARGET] [--providers claude,codex] [--json]`: aggregates verdicts, findings, and disagreements across multiple frontier providers.
- **Bare `openfarm` Automode TUI & command palette (`8f006e3`):**
  - `openfarm_core/automode.py` + `openfarm auto [--once] [--json]` + bare `openfarm` on a TTY launches Automode TUI (non-TTY preserves help + exit 2 for scripts/CI).
  - Detects workspace stage (`empty` -> `init`, `unadopted` -> `adopt`, `adopted` -> `review`/`run`/`unblock`/`new-wave`), summarizes recent economics (worker share, fresh vs. cached tokens), and exposes guided A->B flows plus power tools (`triage`, `frontier-review`, `grill`, `stats`, `dossiers`, `harness`, `acp`, `bench`).
