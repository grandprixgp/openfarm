# openfarm v0.9.2 Build Log

Date: 19 Nov 2026

v0.9.2 redesigns openfarm's TUI to be **high-contrast by default** and turns bare `openfarm` Automode into a **real in-TUI execution pipeline** — eliminating shell-homework checklists for OAuth login, worker API key setup, Grill/spec expansion, and card review.

## Changes

- **High-Contrast TUI Theme by Default (`92456fa`):**
  - `_init_curses_theme()` in `openfarm_core/tui.py` now defaults to `high-contrast` (zero `A_DIM`; `BLACK` on `WHITE` bold brand/active-tab/keycaps, crisp white borders, `BLACK` on `YELLOW` bold selection row, `WHITE` on `RED` bold errors, vivid bold status colors; optional `OPENFARM_TUI_THEME=soft`).
  - Redesigned Overview to lead with the live **Automode Pipeline Hero** (`[✓] Workspace  [▶] Auth  [○] Worker Key  [○] Spec & Cards  [○] Wave`) and removed `$` spend lines in favor of token counts & worker/supervisor shares.
- **In-TUI Automode Pipeline Engine (`92456fa`):**
  - `openfarm_core/automode.py`: `compute_pipeline_stages()`, `list_existing_key_files()`, `save_worker_key_atomic()` (atomic `0600`, `O_NOFOLLOW`, symlink-refusing), `reuse_existing_key_file()`, and `run_grill_and_architect()`.
- **Interactive In-TUI Execution Modals (`ce09c1d`):**
  - `[Enter]` on Overview executes the current live Automode stage directly inside the TUI:
    - Empty folder → prompts name, idea, provider and runs `init` in-TUI.
    - Unadopted repo → runs `adopt` in-TUI.
    - Frontier OAuth not signed in → cleanly suspends curses (`curses.endwin()`), runs `openfarm acp login --provider <p>`, and resumes curses.
    - Missing Worker API key → opens a **masked key modal** (`*`, never logged/echoed) to paste a key or reuse an existing `~/.config/openfarm/*.key` file, written atomically at `0600`.
    - Starter spec/cards → runs interactive 1-question-at-a-time **Grill** in-TUI writing `.openfarm/GRILL_DECISIONS.md` and expanding `.openfarm/PROJECT_SPEC.md`.
    - Wave queue → native in-TUI **Review Modal** (`v`), **Triage** (`t`), **Run** (`n`), and **Land** (`l`), with zero `input()` deadlock.
