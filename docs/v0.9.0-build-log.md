# openfarm v0.9.0 Build Log

Date: 19 Nov 2026

v0.9.0 promotes `counter_tests = "reject"` to the default, adds named supervision profiles (`--profile lean | balanced | strict`), adds `openfarm review` and opt-in local-only `openfarm land`, adds a Go language pack (`openfarm_core/packs/go.py`), adds `vitest` and `jest` runner support to `TypeScriptPack`, and adds polyglot per-unit language configuration under `[units.<name>]`.

## Changes

- **Defaults & named supervision profiles (`50a503b`):**
  - `[gates] counter_tests` now defaults to `"reject"` in `openfarm_core/config.py` and `openfarm_core/config_template.py`.
  - Added `SUPERVISION_PROFILES = ("lean", "balanced", "strict")` and `apply_supervision_profile(cfg, profile)` bundling `shape_when`, `pre_review_when`, `checker_mode`, `counter_tests`, `mutation`, and `confine`, exposed via `openfarm run --profile lean|balanced|strict`.
  - Tests: `tests/test_v090_defaults_profiles.py`.

- **Wave review & local serial merge queue (`78f6056`, `c2308a3`):**
  - `openfarm review`: single-pass review over `in-review` cards (compact dossier + diff + verdict recording: `approve` / `minor-fix` / `bounce` / `skip`), with `--json` / `--verdict` / `--note` non-interactive parity.
  - `openfarm land <CARD...>`: opt-in **local-only** serial merge queue (still zero `git push` code paths anywhere in `openfarm_core/`). Serially trial-merges each approved `in-review` branch onto the local base in a throwaway worktree, runs the verification test gate once per head, merges locally with `git merge --no-ff` (`Git.merge_no_ff`), removes the card worktree, and marks the card `done`.
  - Tests: `tests/test_v090_review_land.py` (full 2-card local git E2E).

- **Go language pack (`5e7198a`):**
  - Added `openfarm_core/packs/go.py` (`GoPack(OwnMutationMixin, Pack)`): `go build`, `go test -json -count=1` (NDJSON parser with per-package footers and build-fail detection), `go test -list .`, `go vet`, `gofmt -w` / `gofmt -l`, banned-pattern scanning (`//nolint`, `os/exec`, `unsafe`, `net/http`, `t.Skip`, production `panic(`), signature extraction, and diff-scoped mutation via `openfarm_core/mutate.py --lang go` (`go_mutants`).
  - Wired `"go"` into `pack_for`, `adopt` (`go.mod` detection and `--lang go`), `config_template.py`, and `cli.py`.
  - Tests: `tests/test_v090_go_pack.py`.

- **TypeScript `vitest` and `jest` support (`81a8823`):**
  - Expanded `[runner] typescript` in `config.py` to `("node", "vitest", "jest")`.
  - Added `vitest` (`vitest run --reporter=json`) and `jest` (`jest --json --ci`) detection, command generation (`-t` filter, local `node_modules/.bin` resolution), JSON result parsing (`_parse_jest_vitest_json`), and `adopt` support in `openfarm_core/packs/typescript.py` and `config_template.py`.
  - Tests: `tests/test_v090_ts_vitest_jest.py`.

- **Polyglot per-unit languages (`fd59130`):**
  - Added `[units.<name>] language = "rust" | "python" | "typescript" | "go"` in `openfarm_core/config.py` with `cfg.language_for_unit(unit)` falling back to `[adapters] languages[0]`.
  - Wired `unit=card.unit` through `_configured_pack` in `openfarm_core/cli.py` (`check`, baseline check, card execution, and `land`).
  - Tests: `tests/test_v090_polyglot_units.py`.
